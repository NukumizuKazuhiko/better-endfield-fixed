# 产品边界

当前项目只开发、验收和发行 Android ARM64 端：LSPosed 模块、配套设置应用与游戏内悬浮面板。Android APK 是当前发行产物，版本与兼容范围以 `android/app/build.gradle.kts`、[Android 快速开始](../android/README.md)和对应发行说明为准。

仓库保留 Windows 控制器、注入器、安装器及其构建脚本，供历史追溯和现有 Android 共用原生源码使用。保留这些文件不代表继续开发、构建、验收或发行 Windows 产品。后续需求不能以历史双端描述为依据把 Windows 路线重新纳入当前目标；若要改变边界，须先明确产品决定，再同步入口文档、构建和验收合同。

当前 Android 发行验收至少核对 APK 构建、入口检查、固定发行签名、资源清单、版本号与 SHA-256。构建或签名通过不等于游戏内实机验收；设备行为按当前用户侧证据单独记录。
